# Rain audio sources

These files are distributed under the Creative Commons Zero 1.0 dedication (CC0-1.0).

- `soft-rain.wav`: SFXMint, Gentle Steady Rain 59, `https://sfxmint.com/sounds/ambience-rain-59`
- `window-rain.wav`: SFXMint, Soft Window-Pattering Rain 60, `https://sfxmint.com/sounds/ambience-rain-60`
- `rain-curtain.wav`: SFXMint, Looping Gentle Steady Rain 31, `https://sfxmint.com/sounds/ambience-rain-31`

The matching `.mp3` files are the versions used by the page for compatibility with older iPhone and iPad Safari releases. The WAV files are retained as lossless masters.

Family and license page: `https://sfxmint.com/sounds/ambience-rain`
